# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## General information

This project is a static website to serve as a training piece and as a personal portfolio.
It shall generally conform to the vibe of "A late summer afternoon."
Stack: This is a static web application, except for the Blog one html page, one CSS setup and JavaScript, no frameworks, no npn, no build tools, no database, no backend, no authentification.

## The specification files

The following files may be read selectively to aquire the context corresponding to the assigned task/area of work.

1. **PRD.md** — vision, personas, feature tiers (Must/Should/Nice-to-Have), technical constraints, success criteria.
2. **content-model.md** — every content field, its meaning, and its constraints (length, tone). Section-by-section.
3. **site-contract.md** — page structure, exact section order, behaviour spec (nav, scroll, hover states per element type, mobile layout changes, animations). This is the most concrete; build against it.
4. **design-standard.md** — the complete visual specification: colour tokens, type scale, spacing system, texture/atmosphere, motion. Authoritative for every colour/type/spacing/motion decision; §7 has a ready-to-paste `:root` token block.
